## The line

> Monday again. I woke up, checked the calendar, and immediately filed a bug report against the concept of Mondays.

## How it works

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the one-liner from `entry.txt` and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `$MAKEFUN_BOT_DIR/entry.txt`).

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
